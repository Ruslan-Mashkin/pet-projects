# Простой калькулятор на Python

Добро пожаловать в мой первый проект! Это простой консольный калькулятор, созданный для обучения работе с Git и GitHub.

## 📋 Описание

Этот проект представляет собой консольное приложение на языке Python, которое выполняет базовые арифметические операции:
- Сложение
- Вычитание
- Умножение
- Деление

## 🚀 Быстрый старт

### Запуск проекта

```bash
python calculator.py
```

### Пример использования

```
=== Добро пожаловать в простой калькулятор! ===
Выберите операцию:
1. Сложение (+)
2. Вычитание (-)
3. Умножение (*)
4. Деление (/)

Введите номер операции (1/2/3/4) или 'q' для выхода: 1
Введите первое число: 10
Введите второе число: 5
Результат: 10.0 + 5.0 = 15.0
```
